# INDUSTRIOM Releases

Repositório público exclusivo para a distribuição assinada do INDUSTRIOM Server, INDUSTRIOM CNC Mobile e AXION.

- O catálogo permanente fica em `catalog/releases.json`.
- A ponte para Servers antigos fica em `catalog/server-update.json`.
- Os binários são assets de releases imutáveis e versionadas.
- SHA-256, assinatura Ed25519, compatibilidade e rollback são verificados pelo Server antes da instalação.

Este repositório não contém código-fonte privado, banco de empresa, programa CNC, credencial, token ou chave privada.
